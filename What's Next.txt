1.1 Was ist AVENYTH?

AVENYTH (Produktname; technischer Namespace im Code bleibt durchgaengig
"numra" — Pakete, DB-Bezeichner, interne Infrastruktur) ist ein
Numerologie-Produkt. Kernprinzip laut Architecture Decision Record
docs\adr\003-llm-not-calculator.md: Berechnungen werden ausschliesslich von
einer deterministischen Engine durchgefuehrt, ein LLM interpretiert nur die
bereits berechneten Werte — niemals umgekehrt.

Verarbeitungspipeline (aus README.md):

  Personendaten (Input)
    -> Normalisierung
    -> deterministische Engine
    -> Canonical Profile (+ Hash)
    -> Knowledge-Resolution (versionierte YAML-Inhalte)
    -> Interpretation / Relationship-Interpretation (regelbasierter Composer + LLM)
    -> Safety-/Claim-Validation
    -> Ausgabe ueber CLI / API / Long-Form-Report-Pipeline / Web / PDF

1.2 Architekturtyp

Modularer Monolith mit mehreren unabhaengig deploybaren Prozessen (kein
Microservice-Mesh, aber getrennte Deployables). Frontend und Backend sind
getrennte Anwendungen, die ueber HTTP kommunizieren.

7.1 Setup

  1. Node >= 20 und pnpm 9.15.0 installieren (siehe package.json,
     "packageManager": "pnpm@9.15.0"). Python >= 3.11 und "uv" installieren.
  2. .env.example im Root nach .env kopieren und alle Werte befuellen (Inhalt
     der Datei bewusst nicht in diesem Dokument wiedergegeben — bitte selbst
     pruefen). Mindestens SESSION_SECRET und PDF_INTERNAL_TOKEN sind fuer
     lokales Docker noetig.
  3. Python-Abhaengigkeiten ueber "uv sync" installieren (Workspace-weit),
     JS-Abhaengigkeiten ueber "pnpm install".
  4. Fuer den vollen lokalen Stack: docker-compose.yml verwendet (Postgres,
     Redis, api, worker, analysis-worker, pdf, web). Fuer eine
     RC2-Testumgebung existiert zusaetzlich docker-compose.rc2.yml und
     scripts\rc2-e2e.sh (up/test/down).
  5. Datenbank-Migrationen: uv run alembic upgrade head (im Kontext von
     apps\api). Neue Migration: uv run alembic revision --autogenerate -m "...".
  6. API lokal ohne Docker starten:
     uv run uvicorn numra_api.app:app --reload --port 8000 --app-dir apps/api/src
  7. Frontend lokal starten: pnpm --filter @numra/web dev (bzw. root-Skript
     "web:dev" aus package.json).
